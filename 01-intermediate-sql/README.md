# Intermediate SQL

This folder contains practical exercises completed as part of DataCamp's Intermediate SQL course.

## Topics covered

- Arithmetic operations and calculated columns.
- Column aliases and data selection.
- Common Table Expressions (CTEs).
- Safe division using `SAFE_DIVIDE`.
- Financial metrics and margin analysis.

## Exercises

### 01. Trade Margin Analysis

**Objective:** Calculate the margin and margin ratio for stock sell trades.

**Key concepts:**
- Calculating sales proceeds and purchase costs.
- Accounting for trading fees.
- Creating calculated columns.
- Using CTEs to reuse calculated values.
- Handling division by zero.

**Financial metrics:**
- `margin`: Absolute profit or loss per trade.
- `margin_ratio`: Profit or loss as a percentage of the total purchase cost.

## Learning approach

Exercises are documented and progressively improved to demonstrate SQL querying skills and practical data analysis techniques.
